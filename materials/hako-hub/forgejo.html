土台ごとの操作

基本は、土台によらず hako の決まったコマンドで対応します。土台の中で直接操作する場合の違いは、下の通りです。

Ubuntu の場合release 型なので apt は使わない。入れる: hako up forgejo（公式バイナリを取得して検証）。消す: hako remove forgejo。上げる: 新しい版のレシピで hako up forgejo の入れ直し
Alpine の場合土台の中で入れる公式バイナリは glibc 前提のため、Alpine の土台では動かない。土台の中で使う場合は Ubuntu の箱で。土台を使わない Bionic 側の道もある（本文）

概要

Git サーバー。同梱をやめて、Hako Hub のレシピから入れる形に移した最初の1つ。

入れ方（release 型）

公式の配布ファイルを取得し、SHA-256 で確かめてから入れる。proot の中では root のままでは起動できないため、専用の非 root ユーザーで起動する。

Bionic 側で動かす道

Forgejo は Go 製で、Bionic 向けにビルドした実績がある（11.0.1）。土台を使わず、Bionic 側の部品として動かせる道がある。Hako@Linux のレシピとして整えるのはこれから。

実測（Pixel 3a）

  • 配布ファイル 103 MB、取得32秒
  • 初回起動15.1秒で応答確認（データベースの初回作成込み）
  • 常駐時のメモリは約155 MiB と大きめ。常時使う場合だけ入れるのがよい
