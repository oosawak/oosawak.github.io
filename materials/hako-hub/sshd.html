概要

箱への入り口の SSH サーバーです。Rust のライブラリ russh で作ったネイティブ部品で、土台（proot）に依存しません。以前の構成で土台の中に入っていた OpenSSH は、もう使いません。

パスワードの照合は Argon2id のハッシュで行います。パスワードが未設定の間は、SSH を開きません。

土台が動いている時は、その土台のシェルへつなぎます。土台が止まっている時は、Bionic 側のシェル（bash、git、curl、基本コマンド）で応答するので、復旧の入り口にもなります。

ファイルのやり取りは SFTP で実ファイルを読み書きできます。ポート転送にも対応し、VS Code の Remote-SSH の基盤になります。

実測（Pixel 4）

  • 本体の大きさ 1.70 MiB
  • 起動 14.0 ミリ秒（鍵の初回生成込みでも 42.7 ミリ秒）
  • 待ち受けのメモリ 2.43 MiB
  • LAN からの接続、PTY、SFTP の往復（64 KiB、ハッシュ一致）、ポート転送まで確認済み
