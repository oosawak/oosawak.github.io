web-and-collector

Web を出す係と、定期的に測って記録する係の組。hako の使い方の見本。

実証済み

ジャンル学習
状態実証済み
方式サンプル（compose 定義）

hako up（compose の定義から）

操作コマンド

入れる定義ファイル（compose.yaml）のある場所で hako up
消すhako down で両方とも停止。片付けは定義ファイルと作業場所を消す
上げる（更新）定義ファイルを書き換えて hako up し直す

概要

hako の使い方の見本。2つのサービスでできている。

  • web: Python で Web ページを出す係
  • collector: 一定間隔で測って、記録ファイルに書き続ける係

確認したこと

学校の Windows の箱で、定義ファイルから起動して、Web の応答と、collector の記録の書き込み、停止後の状態まで確認した。
