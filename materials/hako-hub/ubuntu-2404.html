入れる初回セットアップの時に選ぶ。初期ユーザーとパスワードも、その時に設定する

概要

現行の標準の土台。互換性を優先する用途向けで、パソコン版の箱とも中身を揃えやすい。

実測（Pixel 4）

  • セットアップ 49.0 秒、大きさ 229.9 MiB（SSH サーバーはネイティブ側にあるため、土台には入れない構成）

向いていること

  • code-server や VS Code からの接続（Remote-SSH）など、glibc が要るソフト
  • 公式バイナリをそのまま動かしたい場合
