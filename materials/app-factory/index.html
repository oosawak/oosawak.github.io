DEDICATED APPS

専用アプリは、AIと作る。

1つの大きなアプリに全部を入れるのではなく、用途ごとの小さい専用アプリを作ります。AIエージェントのミューズさんがソースを書き、GitHub に置くと、GitHub Actions がビルドと署名をして、専用の Android アプリが出てきます。

流れ

  1. 用途を決めます。たとえば「バスの位置を記録する」「田んぼに置いて記録する」など、1つの仕事だけです。
  2. ミューズさんがソースを書いて、GitHub のリポジトリへ置きます。
  3. GitHub Actions が自動でビルドし、署名を付けます。
  4. 専用の Android アプリが成果物として出てきます。入れる人は、それを電話に入れるだけです。

中の作り

土台は箱

どの専用アプリも、土台は Hako@Linux の箱です。箱と入り口は共通で、用途ごとに作るのは薄い殻のほうだけです。

仕事は Python

中身の仕事は、箱の中の Python がやります。センサーや位置を読む橋は、もう動いているものを使います。

表示は WebView

画面は Web ページとして Linux 側から出し、アプリは WebView で映します。素の HTML と JavaScript で、ビルドは要りません。表示を出す方向と、操作を Linux 側へ返す方向の、双方向です。

なぜ分けるのか

専用アプリに分けると、権限も機能も、その用途に要るものだけに絞れます。「置きっぱなしロガー専用」「バス専用」「見守り専用」が、それぞれ小さいアプリとして並びます。作る側の手間は、AI が書いて Actions が組むので、以前ほどかかりません。

実例

バスの位置情報

電話1台でバスロケをする構想です。紹介ページと、GPS ログの地図表示の試作があります。

壁紙アプリ

GitHub にソースを置いて Actions で組む形は、壁紙アプリで先に実証済みです。この仕組みの原型です。

部品ごとの実証は済んでいます（箱、センサーの橋、Actions でのビルド）。専用アプリを量産する形としての運用は、これからです。
