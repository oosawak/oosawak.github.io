BOX FRONTEND

箱の顔は、小さなサイトでいい。

Hako@Linux の箱には、管理画面がありません。代わりに、小さなサイトを箱のフロントエンドとして表示する、小さなアプリを作れます。アプリの仕事は、箱が出すサイトを WebView で映すことです。

仕組み

  1. 箱の中の小さなサーバーが、フロントエンドのサイト（HTML と素の JavaScript）を出します。
  2. アプリは、そのサイトを WebView で表示します。アプリ側に画面の作りは持ちません。
  3. サイトでの操作は、普通の Web のリクエストで箱側へ返ります。表示を出す方向と、操作を返す方向の、双方向です。
  4. サイトを直せば、箱の顔が変わります。アプリを作り直す必要はありません。

なぜ小さなサイトなのか

ビルドが要らない

素の HTML と JavaScript なので、そのまま置けば動きます。道具の依存が増えません。

AI が書ける

サイトの形なら、AIエージェントのミューズさんがそのまま読み書きできます。画面の追加や変更が軽くなります。

箱の外でも同じ表示

サイトなので、パソコンのブラウザからも同じものが見られます。管理は電話の画面だけに閉じません。
