## VRM1_Constraint_Twist_Sample.vrm

バトルの主人公として、最初に表示するサンプルの VRM です（自分の VRM を読み込むまでの素体）。

- 入手元: [vrm-c/vrm-specification の samples/VRM1_Constraint_Twist_Sample](https://github.com/vrm-c/vrm-specification/tree/master/samples/VRM1_Constraint_Twist_Sample)（同じものが pixiv/three-vrm の examples にもあります）
- 著作権: (c) 2022 pixiv Inc.
- ライセンス: [VRM Public License 1.0](https://vrm.dev/licenses/1.0/)
- モデルに書かれている利用条件（VRM の meta）
  - アバターとしての利用: 誰でも可（everyone）
  - 商用利用: 可（corporation）
  - 再配布: 可（allowRedistribution: true）
  - 改変: 改変・改変物の再配布とも可（allowModificationRedistribution）
  - クレジット表記: 不要（unnecessary）。このゲームでは画面とこのファイルに表記しています
  - 暴力表現での利用: 可 ／ 反社会的・憎悪表現での利用: 不可

ファイルは手を加えずにそのまま置いています。
