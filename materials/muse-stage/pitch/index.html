Lyre3 Games1 / 11
事業概要

書くことに集中できる、ホームページの仕組み

ホームページの多くに使われるWordPress等の仕組みは、サーバー側でプログラムが常時動き、保守と脆弱性対応の負担が続きます。

本事業は、サーバー側のプログラムを持たない構成にすることでその負担を取り除き、小さな事業者でも無理なく情報発信を続けられるようにします。

オープンソース版は公開済みです。商用版は、デザイン制作と導入に加えて、WordPressからの移管やデザインされたホームページからの移管、SEO対策なども考慮しつつ、AIと一緒に運用するパッケージとして事業化を進めています。

Markdown CMS2 / 11
課題

小さな事業者にとって、安全と更新がいちばんの不安

  • サーバーでプログラムが動き続ける限り、脆弱性への対応が終わらない
  • 管理画面の習熟や専門知識が要り、更新そのものが止まってしまう
  • 小さなパン屋のような事業者の方から、サイトの安全性について「怖い」という声を日常的に聞く

「ホームページを作る仕組み」に見えますが、一般の商売の方にとって、サイトの安全性と更新は、いま一番不安で、一番解決したい問題です。

たかが、ホームページの話です。だからこそ、安心して簡単に運用できる仕組みを考えています。

Markdown CMS3 / 11
独創性

「動かす」ではなく「変換して配るだけ」という逆転

  • サーバーで動かすのではなく、文章を変換して配るだけの構成
  • AIを意識した設計：管理画面を持たず文章ファイルを正本にするため、AI（Meta Muse）と一緒に記事を書いたり、直したり、そのまま公開したりできる
  • AIから直接書ける：置き場所（GitHub／CloudflareのR2）へAIが直接書き込めるため、「書く」から「公開」までが人を介さず一息でつながる
  • 利用者は写真を撮ることと文章を書くことに集中でき、専門知識や管理画面の習熟が要らない
  • ソフト単体ではなく、文章とAI支援を組み合わせた「続けられる発信の仕組み」として提供する
  • サイト、小説、地図、動画、店舗の発信までが1つの土台の上で回るエコシステムである点が、他にはない形

仕組みの全体像

本体は小さく、部品で足せる

microForm（稼働中）

サイトにお問い合わせのメールフォームを足す部品です。

microCMS連携（仕組みを用意）

管理画面が要る人には、既存の管理画面サービスとつなぎます。正本は手元の文章ファイルのままです。

置き場所の選択肢（テスト中）

現在はGitHub Pagesで複数のサイトを運用中です。Cloudflare版とGCP版をテストしています。どの置き場所でも、正本はMarkdownで共通です。

足りないものを全部作り込まず、要る部品だけを足していく設計です。

運用パッケージ

シンプルだから、周辺業務まで面倒が見られる

サイトの仕組みをシンプルに保つ分、先にある周辺業務にも手が回ります。AIとMarkdownの仕組みで、これから準備していく範囲です。

サイト更新の支援

原稿を渡すだけで、AIと一緒に更新が回る形にします。

経理・申告の下処理

レシートから帳簿、申告の下書きまでを下処理します。

セキュリティの見張り

棚卸しをして、危ないものだけを知らせ、承認制で更新し、履歴も残します。この型は私自身の環境で毎朝回しています。

対象は「これから事業を始める人」と「始めたものの周辺業務が回っていない人」の2層です。

地域貢献度・協力可能性

同じ型を、地域ごとに広げる

  • 天童・長井・鶴岡では市町村単位のグルメ地図を公開し、地域の店の情報を地図で回す形を作った
  • 松島の小さなパン屋では、既存サイトをこの仕組みへ移す試作まで進行中
  • 西日本でも、宇和島のグルメサイトを同じ型で公開済み
  • 福岡・九州では、この型を地元の店舗や地域団体、地元の支援機関と組んで広げる
  • 金融機関の取引先である中小企業へのWeb支援という形でも、地域の事業者の役に立てる
Markdown CMS9 / 11
将来性・事業計画／賞金の使途

入口は小さく、届く先は全国

  • 対象は、全国の「更新頻度は低いが保守負担は重い」中小企業・店舗のサイトで、母数は大きい
  • 収益の形は、初期費用（デザイン制作と導入）と月額の運用パッケージを想定（料金体系は準備中）
  • 導入する事業者側は、小規模事業者持続化補助金など公的支援の対象になり得ます
  • オープンソース版で利用者を広げ、商用版で地域ごとの導入支援先と組んで展開する二段構え

賞金の使途：商用版の提供開始に向けた整備（管理画面の仕上げ、案内資料の制作）。福岡・九州での協業先開拓と、導入事例づくりのための検証費用。
