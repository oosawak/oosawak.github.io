## 加工内容（最小限）

- 座標を 1e-5 度グリッド（約1m）に丸めた。元データの位置精度は縮尺 1/25,000 相当（概略位置）で、法的境界ではない。
- 洪水・津波は格子セル状のポリゴンのため、同じ属性値のセル同士を結合し、結合後の階段状境界を許容誤差 5e-5 度（約5m、元データ精度の誤差範囲内）で簡略化した。結合は処理都合で空間タイルごとに分かれるため、同じ属性値のポリゴンが複数フィーチャになる。異なる属性値同士の重なりは残るため、判定側では該当する最大のランクを採用すること。
- 洪水は河川種別 10（洪水予報・水位周知河川）と 20（その他の河川）を1ファイルに統合した。
- 土砂は区域ごとの個別ポリゴンのまま（結合していない）。
- 属性は元のコード名・値のまま残した（下記凡例参照）。

## 属性の凡例（最小限）

### 土砂災害警戒区域（A33_*）
- A33_001 現象の種類（コードリスト「現象種別コード」: 急傾斜地の崩壊 / 土石流 / 地すべり）
- A33_002 区域区分（コードリスト「区域コード」: 土砂災害警戒区域＝イエローゾーン / 土砂災害特別警戒区域＝レッドゾーン）
- A33_003 都道府県コード / A33_004 区域番号 / A33_005 区域名 / A33_006 所在地 / A33_007 告示日
- A33_008 特別警戒未指定フラグ（イエローのみ公示し、レッドの調査・公示を行っていない区域）

### 洪水浸水想定区域（A31b_*）
- flood-*.geojson の属性は A31b_201（想定最大規模の浸水深ランク、コードリスト「浸水深ランクコード」: 1=0.5m未満, 2=0.5〜1m, 3=1〜2m, 4=2〜5m, 5=5〜10m, 6=10〜20m, 7=20m以上）
- flood-duration-*.geojson は浸水継続時間ランク、flood-collapse-flow / -erosion は家屋倒壊等氾濫想定区域の区分コード（各ファイルの属性名は元のまま）。

### 津波浸水想定（A40_*）
- A40_001 都道府県名 / A40_002 都道府県コード / A40_003 浸水深区分（文字列、例「0.01m以上 〜 0.3m未満」）
- 山形県分は 2016年度整備と古い。表示時はデータ時点を明記すること。

## 判定方法（ボード側の想定）

- 登録地点のある県（土砂・津波）またはメッシュ（洪水）のファイルだけを読み、point-in-polygon で判定する。
- 洪水で複数ランクに該当する場合は最大ランクを表示する。
- 区域の位置は概略であり、判定結果は目安として表示し、データ時点と併記すること。
