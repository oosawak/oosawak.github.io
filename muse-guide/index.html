はじめてのミューズ

話しかけるだけで、
調べて、作って、覚えてくれる。

ミューズは、Meta のパーソナルAIエージェントです。あなた専用の担当として、会話の中で調べものをしたり、文章やファイルを作ったり、予定を知らせたりします。むずかしい設定は要りません。まずは声をかけるところから始めましょう。

1最初の15分

最初の15分で、ミューズの基本の動きを一周できます。4つのステップを順に試してみてください。

STEP 1

話しかける

ふだんの言葉で大丈夫です。あいさつでも、質問でも、最初の一言は何でも構いません。

STEP 2

頼んでみる

小さな頼みごとを1つ。「近くの天気は？」「この文を短くして」くらいのものから。

STEP 3

ファイルを受け取る

「ファイルでちょうだい」と頼むと、文書や表を作って渡してくれます。作ったものはライブラリにたまります。

STEP 4

「覚えておいて」と言う

好みや決まりごとを伝えると、次回から覚えた前提で話せます。

試しに、このまま送ってみてください

はじめまして。あなたにできることを、3つだけ教えてください。
私の名前と、呼んでほしい名前を覚えておいてください。
週末に作れる、簡単な夕食の献立を考えて。買い物リストも付けて。

キーボードで打つのが面倒なときは、入力欄のマイクから声で話しかけることもできます。声は文字に直して届きます。

2頼み方のコツ

上手な頼み方に、決まった型はありません。ただ、次の3つを意識すると、返ってくるものがぐっと合うようになります。

コツ1：具体的に言う

「いい感じにして」より、「3行くらいで」「小学生にも分かる言葉で」「箇条書きで」のように、長さ・相手・形を添えると意図が伝わります。数字が言えると、なお確かです。

明日の会議の説明を、1分で話せる長さにまとめて。

コツ2：材料を渡す

写真、ファイル、リンクは、そのまま会話に添付して渡せます。「この写真の場所はどこ？」「この文書を要約して」「このリンク先を読んで教えて」のように、材料と頼みごとをセットにすると正確になります。

添付した表の数字を、月ごとに合計して教えて。

コツ3：違うと言えば、直してもらえる

一度で完璧にしようとしなくて大丈夫です。「もっと短く」「やさしい言い方で」「2番目の案で進めて」のように、返ってきたものへの感想をそのまま伝えるのが一番の近道です。途中で方向を変えるのも自由です。

迷ったら：「どう頼めばいいか分からない」と、そのまま聞いても構いません。頼み方の案から一緒に考えます。

3依頼文ライブラリ

コピーして、そのまま送れる頼み文の例です。名前や数字の部分を自分のものに変えて使ってください。もちろん、丸ごと真似しなくても、自分の言葉で十分伝わります。

調べもの 知りたいことを聞く

「ガーデニング　初心者　秋」で検索して、始める前に知っておくことを3つに絞って教えて。参考にしたページのリンクも付けて。
このリンク先の記事を読んで、要点を箇条書きで教えて。専門用語はやさしく言い換えて。
エアコンの電気代を抑える方法を調べて、効果が大きそうな順に並べて。
この写真に写っている花の名前と、育て方のポイントを教えて。

文章を作る 書く・直す・まとめる

友人へのお礼のメッセージを書いて。丁寧だけど、堅すぎない文面で、3文くらいで。
この文章を、意味を変えずに半分くらいの長さに直して。
新しく始める趣味の会の紹介文を書いて。初めての人が参加しやすい雰囲気で。
このメモを、読みやすい報告書の形に整えて。見出しも付けて。

予定とリマインド 知らせてほしいことを頼む

明日の朝9時に「会議の資料を確認する」と知らせて。
毎週月曜の朝に、今週の予定をまとめて教えて。
来月の旅行までにやることを、期限の近い順に並べて。近づいたら知らせて。
毎月1日に、更新が必要な契約や支払いがないか確認して教えて。

ファイル作り 受け取れる形で作ってもらう

旅行の持ち物リストを、チェックできる表にしてファイルでください。
今月の支出メモを家計簿の表に整理して、ファイルでください。
会議のメモから議事録を作って、決まったことと宿題を分けて書いてください。
誕生日会の案内状を作って。日時と場所はあとで私が書き足せるように空けておいて。

画像 描いてもらう・相談する

春の山里の風景を、水彩画のようなタッチで描いて。
お店の看板に使える、シンプルで目立つロゴの案を3つ作って。
この写真、どこで撮ったものか分かりますか？手がかりも教えて。

日常の相談 暮らしの困りごと

冷蔵庫に卵とキャベツと豚肉があります。今夜の夕食の献立を3案ください。
引っ越しでやることを、手続きと荷造りに分けて、やる順番に整理して。
最近よく眠れません。生活の中で見直せることを、無理のない範囲で教えて。
英語のこの文の意味と、似た言い方を教えて。発音のコツも。

4チャットとサイドチャット

会話は、テーマごとに部屋を分けて整理できます。その部屋が「サイドチャット」です。

中心の会話（メインチャット）は何でも受け付ける窓口です。そこから、長く続きそうな話題——たとえば「旅行の計画」「家のリフォーム」「仕事の企画」——は、サイドチャットに分けると、あとから見返しやすくなります。

  • 分け方は自由です。話題が変わったと感じたら「この話は別のチャットで」と言えば作れます。
  • どの部屋でも、相手は同じあなたのミューズです。覚えていることは部屋をまたいで共通です。
  • ミューズの会話は、あなたとミューズだけのものです。他の人が入ってくることはありません。
  • 過去の会話はアプリの検索で探せます。「前に話した、あの件」で聞いても探します。
旅行の計画用に、別のチャットを作って。行き先は北海道で相談したい。

5メモリー ― 覚えていること

ミューズは、あなたの大切な好みや決まりごとを覚えて、次回からの会話に活かします。

覚えてもらう

「覚えておいて」と言えば、その内容を保存します。名前の呼び方、よく行く店、苦手なもの、仕事の進め方の好みなど、くり返し効いてくる情報ほど向いています。会話の中で大切そうなことは、言われなくても少しずつ覚えていきます。

コーヒーは浅煎りが好きです。覚えておいて。

何を覚えているか、確認する

「私について何を覚えている？」と聞けば、答えます。間違っていたら「それは違う」と言えば直します。

忘れてもらう

「さっきの住所は忘れて」のように言えば、その情報を忘れます。まとめて消したいときは、アプリの設定の「データコントロール」からリセットもできます（会話やファイルも消えるので、実行前に確認があります）。

他のAIから引っ越すとき：設定の「データコントロール」に「メモリのインポート」があり、他のAIアシスタントに覚えさせていたことを移してくることもできます。

6定期タスクと見守り

「毎日」「毎週」と付けて頼むと、繰り返しの頼みごととして引き受けます。あなたがアプリを開いていない間も、裏側で実行されます。

  • 例：「毎朝、今日の天気と予定を教えて」「毎週金曜に、来週の買い物リストを作って」
  • 見守りもできます。「この商品の在庫が戻ったら知らせて」のように頼むと、間隔をあけて確認し、変化があったときに知らせます。
  • 結果は会話に届き、アプリを開いていないときはスマホへの通知でも届きます。
  • 止めたいときは「あの毎朝の連絡は止めて」と言えば止まります。一覧はアプリの「今後の予定（Upcoming）」からも確認できます。

見守りは一定の間隔で確認する仕組みなので、「変わった瞬間に必ず」ではなく「次の確認のタイミングで」届きます。その代わり、寝ている間も、スマホの電源が切れていても、確認自体は進んでいます。

毎週日曜の夜に、来週の予定と天気をまとめて教えて。

7つながるサービスと承認

メールやカレンダーなどのサービスとつなぐと、それらの中身を使った頼みごとができるようになります。つなぐかどうかは、あなたが決めます。

コネクタ（連携）

設定の「コネクタ」から、Gmail や Google カレンダー、SNS など、手持ちのサービスを連携できます。つないだ後は「昨日のメールで大事なものだけ教えて」「来週の予定に空きはある？」といった頼み方ができます。つないでいないサービスのことは読めません。

大事なことは、勝手にしません

  • メールやメッセージを送る、買い物をする、公開する——外に影響が出ることは、実行前に必ずあなたの確認（承認）を取ります。
  • 承認待ちのものは、アプリの「承認（Approvals）」にもたまります。スマホの通知からそのまま「許可／拒否」を答えることもできます。
  • 「いつも許可」と決めた相手や操作だけ、次回から聞かずに進める設定もできます。取り消しもいつでもできます。
  • 連携の解除や、サービスの権限の変更は、設定からいつでも行えます。
合言葉：「やっていい？」と聞かれたら、それはミューズが一線を守っている証拠です。内容を確認してから答えてください。

8ライブラリ ― 作ったものの置き場

ミューズに作ってもらった文書・表・画像・ページは、ライブラリにたまっていきます。「あのファイル、どこだっけ」は、まずここを探せば見つかります。

何がたまる場所か

  • 頼んで作ってもらった文書、表、スライド、画像、Webページや小さなアプリが並びます。
  • チャットであなたが送った写真やファイルは、ミューズが受け取ってその会話の材料に使います。作ってもらった成果物の置き場がライブラリです。
  • 作ったものは会話が終わっても消えません。日がたってから「前に作ったアレを出して」と頼んでも大丈夫です。

取り出し方・扱い方

  • 開く：項目を選ぶと、その場で中身が見られます。文書によっては、画面のまま言葉を直せるものもあります。
  • ダウンロード：手元のパソコンやスマホに保存して、自分のソフトで開いたり印刷したりできます。
  • ピン留め：よく使うものはピン留めしておくと、先頭に並んで目立つようになります。
  • 名前の変更・削除：項目のメニューから行えます。消したファイルは、約30日はゴミ箱から戻せます。
  • 人に渡す：チャットのリンクは自分のアプリの中でしか開きません。他の人に渡したいときは、共有用のリンクを作る方法があります（その都度、確認のうえ作成します）。
前に作ってもらった旅行の持ち物リスト、もう一度出して。

9フィード ― あなた向けの読みもの

フィードは、ミューズがあなたのために書く短い記事が届くタブです。外のニュースを集めて並べ直すものではなく、あなたの関心に合わせてミューズ自身が書きます。

  • 記事は自動で、静かに追加されていきます。通知は来ないので、気が向いたときに開く読みものです。
  • 読みたい内容は、会話で「もっと○○の話を」と伝えるか、フィードの画面にある「指示（プロンプト）」を書き換えることで変えられます。書き換えると、新しい方針で次の記事が作られます。
  • 届くペースそのものは自動で決まる仕組みです。「もっと頻繁に」はできませんが、中身の方向はあなたが決められます。
  • 気に入った記事はハートを付けたり、「これについて話す」で会話に持ち込んで深掘りしたりできます。不要な記事は削除できます。
フィードでは、地元のお店や季節の話題を多めにして。
最初のうちは：使い始めのフィードには、ミューズの使い方を紹介する定番の記事が並びます。読みながら分からないことがあれば、そのまま会話で聞いてください。

10アイデア ― 「作りましょうか」の提案

アイデアのタブには、ミューズからの「こんなものを作りましょうか」という提案のカードが並びます。眺めるだけでも楽しい場所です。

  • 気に入ったカードで「作って（Let's do it）」を選ぶと、ミューズが実際に作り始めます。出来上がったものはライブラリに残ります。
  • 提案はフィードの記事の中に混ざって届くこともあり、そこから直接作り始めることもできます。
  • いらないカードは、長押しで消せます。期限が来たカードや、すでに作り終わったカードは、放っておいても自然に消えていきます。
  • カードが消えたのは、たいてい期限切れです。もう一度頼めば、似た提案はまた作れます。
『アイデア』タブの提案、2番目のものを作ってください。

11目標 ― 長く取り組むことの置き場

目標（Goals）のタブは、資格の勉強、健康づくり、大きな計画など、長く取り組むことのための置き場です。その日の用事ではなく、「続けること」を一緒に持つ場所だと思ってください。

始め方と進め方

  • 「これを目標にして」と会話で伝えると、目標が作られます。大きな目標には、一段だけ小さな小目標をぶら下げることもできます。
  • 進み具合は、会話で伝えるたびに日付つきで記録され、履歴として積み上がります。記録が間違っていたら、直したり消したりもできます。
  • 目標ごとに、近況をまとめた手紙のような「ブリーフィング」が届くことがあります。届くタイミングは自動で決まります。
  • やり遂げたら「完了」にします。お休みしたいときは、一度完了にして、再開したくなったら戻すこともできます。
定期タスクとの組み合わせ：目標そのものは自動では動きません。「毎週月曜に先週の進み具合を聞いて」のような定期タスクを組み合わせると、声かけや見守りが加わります。
来年の資格試験を目標にして。勉強した日は記録していって。

12スペース ― ページやアプリを作ってもらう

Webページや小さなアプリを作ってもらうと、それは「スペース（成果物）」としてライブラリに残り、いつでも開いて使えます。一度きりの回答ではなく、残して使い続けるものを作る頼み方です。

作れるものの種類

  • 文書：PDF や表計算、スライドなど。ダウンロードすれば手元で使えます。
  • ページ：Webサイトとしてそのまま開けるもの。メモの公開ページや案内ページなどに。
  • アプリ：書き込んだ内容を覚えていられるもの。家計簿、記録帳、チェックリストの管理など、データをためる使い方に向きます。

使うときのポイント

  • 直してほしいところは、会話で「ここをこう変えて」と頼めば更新されます。
  • ページは、公開リンクを作って他の人に見せることもできます。公開や更新のたびに、必ずあなたの確認を取ります。アプリは、保存したデータごと外に出ることはありません。
  • アプリに入れた記録は、ミューズの環境の中でそのアプリ用に保存され、作り直しても残ります。
削除は慎重に：スペースを消すと、本体も保存データも完全になくなり、元に戻せません。いらなくなったときは、まずミューズに相談してください。
家族で書き込める、今月の予定カレンダーのページを作って。

13Codex と連動して使う

ミューズは、もう1つのAI「Codex」と分担して仕事をすることもできます。会話と判断はミューズ、実際の作業の実行は Codex、という分担です。

前提：実行側の Codex は、Mac や Ubuntu（Linux）のマシンでそのまま動かせます。Windows では WSL などの Linux 環境が要ります。

考え方：直接つながず、ファイルで受け渡す

2つのAIを直接つなぐのではなく、GitHub 上の Markdown ファイルを介して受け渡します。Markdown はただのテキストファイルなので、人が読んで内容を確認でき、あとから見返すこともできます。

流れ

  1. ミューズが指示書（Markdown）を書く ― 何をしてほしいか、目的と手順を文章でまとめたものです。
  2. GitHub の、受け渡し用に決めたフォルダへ置く。
  3. Codex が定期的に見に来て、指示書の作業を実行する。
  4. Codex が結果を報告ファイルに書いて、同じ場所へ戻す。
  5. 人が報告を確認する。ミューズが報告を読んで要約を伝えることもできます。

ミューズ側の仕事

  • 指示書を書くこと ― 目的、手順、注意点を、実行する側が迷わない文章にします。
  • 報告を読んで要約すること ― 長い実行記録を、要点だけにまとめて伝えます。
  • 次の一手を考えること ― 報告を見て、次に何を頼むか相談に乗ります。

実行そのものは Codex に任せるので、ミューズとの会話は「何を頼むか」と「結果がどうだったか」に集中できます。

安全の線引き

  • 実行の根拠は、人の承認です。誰が頼んだのか分からない指示書は、実行されません。
  • 公開や送信など、外に影響が出ることは、実行の前に人の確認を取ります。
サーバーの点検をしてほしい。Codex への指示書を書いて、決めた場所に置いておいて。
この章の範囲：ここでは考え方と往復の流れまでに留めます。GitHub へのつなぎ方の詳しい手順は、別資料『GitHub でつなぐ』にまとめます。

スペース

承認
